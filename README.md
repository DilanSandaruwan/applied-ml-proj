## Overview
This project forecasts urban fine particulate pollution ($PM_{2.5}$) across the Colombo metropolitan corridor using **Gaussian Process Regression (GPR)** with an anisotropic Matérn 5/2 covariance kernel, providing exact Bayesian uncertainty quantification alongside local and global model interpretability using **SHAP** and **Partial Dependence Plots (PDP)**[cite: 1, 2].
